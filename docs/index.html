03 / KNOW WHAT YOU ARE SEEING
Inspectable results.
Explicit limits.
All ten clips use the same source garment, nominal medium material, and two-second horizon. A “passed” badge only means the historical sampled-frame checks passed. It does not establish real-cloth accuracy or solver superiority.
Failed PhysX cases stay visible, including self-intersection and motion-check failures. XPBD uses ClothForge contact extensions; the adapter is not a continuous collision detection guarantee.
The browser displays vertex positions rounded to 10⁻⁶ m. Original NPZ files, validation records, initialization records, and hashes are included. GPU runtimes were not re-run for this release.
